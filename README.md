# 奶龙打地鼠 EvokerCue

魔兽世界正式服插件，当前版本 **0.8.14**。提供奶龙个人技能轴提醒、绿喷保护、心火监控、语音提醒与战术板。

## 安装

下载本仓库 ZIP，将其中的 EvokerCue 文件夹放入 World of Warcraft/_retail_/Interface/AddOns，游戏内输入 /reload，再输入 /evc 打开设置。

详细使用说明见 [EvokerCue/README.txt](EvokerCue/README.txt)，更新记录见 [CHANGELOG](EvokerCue/CHANGELOG.md)。

作者：韶光逍珑。

支持正式服 12.1.5（Interface 120105）。修复副本外声音测试静默：手动测试可在副本外使用，总开关关闭时明确提示；自动提醒继续遵守原有限制。

暂时禁用溜溜球（时空畸体 373861）与梦境织机并隐藏相关入口，保留源码和已有方案数据。其他技能、绿喷判定和配额保持原有行为。

回归使用 Lua 5.1 与模拟 WoW API，兼容声明不代表完成游戏内实战验收。完整更新见 [更新记录](EvokerCue/CHANGELOG.md)。

## 0.8.10

默认采用游戏内置 TTS；在“设置 → 声音 → 语音来源”可切换原内置语音包，十个 OGG 保持原样。首次升级选择 TTS，保留其他设置与方案数据，之后保留手动选择。

复用 SFD 的 SpeakText 调用方式，默认语速 0、音量 100，提供客户端可用音色选择；不依赖 SFD 运行，不调用全局停止 TTS。已提交给游戏的短句可能继续读完，本地间隔是估算；没有把 API 请求提交当成已确认出声。

缺少 TTS 或可用音色时明确提示，可切换语音包。副本外手动测试修复、自动提醒边界与球/梦境织机禁用策略继续保留。备用游戏警告音独立保留。本版不修改绿喷计数逻辑。

TTS、语音包、功能禁用及原功能恢复四套模拟回归通过；尚未游戏内试听或实战验证。

## 0.8.11 · P0

兼容当前客户端的字符串施法条 ID，同时保留旧数字 ID。起手与结束仍需同一可读身份，完成状态必须明确；错误身份、受保护字段、中断和重复事件不补算。

可确认归属的绿喷成功释放后，计数与提醒正常提交。配额不可靠时记录具体原因；多个候选提醒无法确定归属时仍保留，不因超时盲目清空。计划完整性不足不会被升级强行确认为可靠。

保留本地参数类型诊断；不修改已有存档、战术板、方案或其他插件。14组P0模拟用例及功能禁用/恢复、TTS、语音包回归通过，游戏内复测仍待完成。
