奶龙打地鼠 EvokerCue 0.8.7

安装：将 EvokerCue 文件夹放入 World of Warcraft\_retail_\Interface\AddOns，覆盖旧版。游戏内输入 /reload 重新加载。
输入 /evc 打开设置，左下方【功能】为原有设置，【战术板】为 Raidary Plan。

Raidary Plan 基本格式：
00:01 韶光逍珑 静滞
00:02 韶光逍珑 梦境吐息
00:30 韶光逍珑 释放静滞

也接受 {time:0:01} - 韶光逍珑 <静滞>、{spell:370537}、spellid:370537、法术链接与独立技能 ID。
保存：保存原文，不切换来源。保存并启用：将 Raidary Plan 设为提醒来源。
解析预览：预览草稿中属于本人的支持技能，不修改正在运行的战斗计划。
未保存草稿会保留；修改中的内容与已保存的正式方案分开。
开怪时读取已保存的选定方案；战斗中的修改下一场生效。

本次保留所有现有提醒、绿喷保护、心火监控、语音和其他战术板来源。
溜溜球识别与战斗提醒、自动排轴将在后续实现。

Raidary Plan 0.8.8 使用方法
/reload 后输入 /evc，点击窗口左下方“战术板”。
从方案下拉框选择已有方案，或新建、复制。名称和首领字段自动保存，正文先写入各自草稿。
输入格式：00:01 韶光逍珑 静滞。也兼容既有 MRT 时间和法术标签。
在“适用首领”中按副本选择首领，无需输入名称或查询 ID；副本外也可提前编辑。
“通用方案（不绑定首领）”可正常保存和启用。“自动使用”设置所选首领的默认方案，再“保存并启用”接入提醒。
“取消绑定”会回到通用方案。旧绑定无法识别时保留原数据，请重新选择首领。
开怪时按战斗 ID 优先、首领完整名称其次选择已绑定方案；否则使用当前选中的通用或本首领方案。
首领不匹配时不会使用其他首领的专属方案。编辑器仍保留自己正在编辑的方案。
“检查”刷新右侧本人安排；“恢复上次保存”取回一个历史版本作为草稿，需保存才生效。
“恢复删除”恢复最近删除的方案及草稿，不恢复自动绑定，避免覆盖后续绑定。
本场战斗的提醒快照不会被编辑、保存或方案切换修改。
本版尚未加入溜溜球提醒及自动排轴。
